A. WHAT CHANGED
----------------------------------------------------------------

1. Important: logout waits for the server (Ruling 12).
- App.tsx logout(): clears logoutError, then awaits api.logout(). setAuth('out') runs only
  after the request succeeds. On failure, logoutLocks(e) decides: a 401 locks the shell (the
  ApiClient's onUnauthorized has already done so); any other failure keeps the user 'in' and
  sets logoutError to LOGOUT_ERROR_TEXT = 'Could not log out. Try again.'
- Shown inline in the header: <span role="alert" data-testid="logout-error"> next to the
  Log out button (wrapped in .shell-header-actions). Cleared at the start of each attempt.
- The decision is the pure function logoutLocks(e) in the new shell/logout.ts, unit-tested in
  shell/logout.test.ts.

2. Important: an expired session ends the UI even when the socket cannot tell (WsClient
   retries forever otherwise).
- App.tsx, the auth === 'in' effect now subscribes ws.onStatus(s => ...). On 'closed'
  (WsStatus is 'connecting' | 'open' | 'closed', checked in net/ws.ts), it calls
  api.session(): ok === false -> setAuth('out'); a rejection is ignored (the network is down
  and the socket's backoff continues).
- The cleanup unsubscribes (offStatus()) before ws.close(), so closing never triggers a check.
- The listener is subscribed before ws.connect(), so an immediate refused upgrade is caught.

3. Minors:
- Login.tsx: the passphrase input is focused on every mount (useRef + useEffect). autofocus is
  kept.
- Login.tsx: submit is ignored when the passphrase is empty (passphrase === '' return). The
  input has required and name="password".
- App.tsx: window 'online' calls ws.kick(); the visibility effect now removes both listeners
  on cleanup.
- AppList.tsx: subscribes ws.onStatus and calls load() on 'open'; the subscription is removed
  on unmount, alongside the build.task listener.
- shell.css: .shell-header-actions and .shell-header-error (the error wraps at phone width).

Files changed: App.tsx, AppList.tsx, Login.tsx, shell.css (modified); logout.ts, logout.test.ts (new).
