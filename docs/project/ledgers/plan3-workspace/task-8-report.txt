SELF-REVIEW NOTES
- Values and behavior follow the brief verbatim: WS_PATH, HEARTBEAT_MS, the 404 and
  401 status lines and bodies, the broadcast/sweep/handleMessage semantics and the
  exact pong JSON key order (type, t).
- Compatibility with the client (apps/client/src/net/ws.ts): the client sends
  {type:'ping',t} every 25s and treats a missing pong within 10s as a dropped
  socket. The server answers with {"type":"pong","t":t}, which parseServerMsg accepts
  ('pong' is in SERVER_MSG_TYPES). Protocol-level ws pings are answered by the browser
  automatically and feed markAlive through the 'pong' event, so the 30s sweep does not
  drop live browsers.

ADDITIONS BEYOND THE BRIEF (small, deliberate)
1. refuse() adds socket.on('error', destroy) before writing the refusal. Node's http
   server removes its own socket error listener once an 'upgrade' is emitted, so a
   client reset during a 401/404 would otherwise surface as an unhandled 'error' and
   crash the process.
2. close() also calls server.off('upgrade', onUpgrade), so a closed attachment stops
   handling upgrades.
3. close() copies wss.clients before terminating each client.
4. The "closed sockets leave the hub" test first waits for hub.size() === 1, so the
   final size-0 assertion cannot pass trivially.
5. Rejected-connection tests also assert hub.size() === 0.

CONCERNS
- The hub's membership depends on the ws 'close' event. close() terminates clients,
  and that event fires asynchronously, so hub.size() drops to 0 shortly after
  close(), not synchronously. The brief does not ask close() to clear the hub. The
  owner of the SocketHub should not assume it is empty right after close().
- The brief's convention "no Date, Math.random or I/O in src" is met by hub.ts.
  attach.ts does network I/O (WebSocketServer and a setInterval) because the task
  requires it. This is expected for a server module.
- sweep() calls ping() and terminate() without a try/catch. For ws sockets in the hub
  (always OPEN when added) neither throws. A socket whose ping threw would abort the
  rest of that sweep.
