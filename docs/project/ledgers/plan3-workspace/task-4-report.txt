  migration in its own db.transaction that executes the SQL then sets

  PRAGMA journal_mode = WAL. Then foreign_keys = ON, busy_timeout = 5000, then migrate.

----------------------------
1. The conventions line says "No Date, Math.random or I/O in src". db.ts does I/O
   (mkdirSync and opening the database file), because the brief requires it. config.ts
   already reads files. I followed the brief. The controller should confirm that the

   migrations. If two processes open the same new file at the same moment, one fails on

   BEGIN IMMEDIATE guard. Flag this if multi-process access is expected.
