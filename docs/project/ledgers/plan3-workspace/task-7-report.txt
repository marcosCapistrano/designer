apps/server/src/apps/registry.ts
  - export interface AppEntry { name, dir, adopted, manifest, manifestError }
  - export class AppRegistry(appsDir)
      list()     every git checkout directly in appsDir, sorted by name;
                 a missing appsDir gives []. Rescans on every call, no cache.
      get(name)  one app, or null for an unknown name or an unsafe name.
                 Stats only that one directory.
  - An app is a non-hidden directory directly in appsDir that contains a
    .git entry (directory or file).
  - Manifest read from <dir>/.hub/app.json via parseAppManifest from
    '@hub/protocol/manifest' (APP_MANIFEST_FILE for the path):
      absent                 -> adopted false, manifest null, manifestError null
      unparsable / invalid   -> adopted false, manifestError = parser error
      name != folder name    -> adopted false,
                                manifestError = manifest name "X" does not match
                                the folder name "Y"
      otherwise              -> adopted true, manifest set, manifestError null

SELF-REVIEW NOTES
-----------------
  - Invariant: adopted === (manifest !== null). On the name-mismatch case the
    parsed manifest is NOT returned (manifest stays null), matching the
    unparsable case.
  - list() sorts the candidate names with the default sort (UTF-16 code
    unit order), not localeCompare, so the order does not depend on locale.
  - list() filters names before stat, so hidden entries and plain files are
    never stat'ed for .git.
  - Symlinks are followed (stat, not lstat). A symlink to a git checkout is
    listed under the link's name.
  - Errors from readdir other than ENOENT are rethrown. A missing appsDir is
    the only case treated as empty.
  - A read error on .hub/app.json other than ENOENT does not throw. It is
    reported in manifestError as ".hub/app.json could not be read (CODE)",
    so one broken app does not fail list() for all apps. The message carries
    only the errno code, not an absolute path.
  - Checked by hand with a throwaway script in the scratchpad (not committed):
      .hub is a regular file  -> manifestError ".hub/app.json could not be
                                 read (ENOTDIR)"
      no .hub directory       -> absent (no error)
      symlink to a checkout   -> listed, followed
      get('.hidden'), get('') -> null
  - Input arrays are not mutated: filter() returns a new array before sort().
