WHAT CHANGED
------------
1. shell-lexer.ts is one left-to-right pass that returns a flat list of simple commands. Each word
   is {text, dynamic, expanded, bracketed}; each command has a heredoc flag. It reads:

   - $(...), <(...), >(...), backticks (body un-escaped, then lexed on its own), ${...}
