    * resume = store.chatSession(app) ?? undefined; runner.run({ cwd, prompt, resume, systemPrompt: buildSystemPrompt(branch), signal }).
    * text events -> 'assistant' message; tool events -> 'tool' message via summarizeTool(name, input, cwd).

      parseUsageLimit(error) === null, error !== 'aborted'. Before the retry: setChatSession(app, null) and a

    * Result: limit parsed -> { ok:false, error, limited:true, resetsAtMs }; ok -> { ok:true, error:null, limited:false, resetsAtMs:null };

  - queueAfterLimit(deps, task, prompt, result): retryAt = resetsAtMs ?? now() + USAGE_RETRY_FALLBACK_MS;
    updateTask { status:'queued', retryAt, pendingPrompt: prompt, error: null }; 'status' message
    "Claude usage limit reached. The Hub will retry at HH:MM UTC."; publishTask(..., false); returns the queued task.
